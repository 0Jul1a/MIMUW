## Introduction to Machine Learning 
This repository contains two major data science projects covering image processing using clustering, feature extraction,
non-linear classification, dimensionality reduction, feature selection, and high-dimensional regression modeling.

All solutions are provided as fully executable Jupyter Notebooks (`.ipynb`) containing embedded plots, data processing pipelines, and analytical commentary.

---

| Project | Location | Stack & Tools | Focus Areas |
| :--- | :--- | :--- | :--- |

| **Project 2: High-Dimensional ML Modeling** | [`/project_2`](./project_2) | `Python`, `scikit-learn`, `Google Colab` | High-Dimensional Feature Selection, Hyperparameter Tuning, Resampling, Logistic/Linear Regression |
