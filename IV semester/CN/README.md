## Computer network

A collection of my C++ projects developed for the Computer Networks course @ MIMUW. 
These projects focus on communication protocol, message handling, synchronization logic,  and audio stream demultiplexing over TCP/UDP.

All projects are written in ISO C++20 and designed to compile cleanly under strict GCC/Clang flags without memory leaks.
