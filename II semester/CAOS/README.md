# Computer Architecture and Operating Systems
This repository contains my solutions to three low-level programming assignments for the **Computer Architecture 
and Operating Systems** course @ **MIMUW**.

## Projects overview

### 1. Moore Automata Simulator
 * **Language:** `C`
 * **Directory:** [`./moore-automata/`](./moore-automata/)
 * **Description:** a dynamically loaded C library simulating a deterministic, finite-state, binary Moore machine.

### 2. N-bit Integer Inversion (`ninv`)
* **Language:** `x86-64 Assembly`
* **Directory:** [`./ninv/`](./ninv/)
* **Description:** an assembly implementation of an n-bit integer inverse function callable from C, supporting integers up to 256000 bits.

### 3. File Reversal Program (`freverse`)
* **Language:** `x86-64 Assembly`
* **Directory:** [`./freverse/`](./freverse/)
* **Description:** an assembly program that allows the user to reverse the contents of a file of any size, using Linux system calls.

> **Note:** Only the implementation files (`.c`, `.asm`) are my own work. All assignment specifications and mathematical formalisms belong to their original authors @ **MIMUW**.
